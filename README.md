Instrucciones para el uso del programa:

1. *Clonar el repositorio*:
   - Esto permite que el usuario descargue tu proyecto y lo tenga listo en su máquina.

2. *Instalar dependencias*:
   - npm install instala todas las librerías necesarias para que la app funcione.

3. *Obtener y reemplazar la clave API*:
   - El usuario necesita obtener una clave API de WeatherAPI y colocarla en el archivo *App.js*.

4. *Ejecutar la aplicación*:
   - npx expo start es el comando necesario para iniciar la app con *Expo*.
   - Expo abrirá una página en el navegador con un *QR code* para que el usuario escanee con su celular y vea la app en acción.

5. *Probar la funcionalidad*:
   - Después de escanear el código QR, el usuario podrá ingresar el nombre de una ciudad y obtener los datos del clima.
